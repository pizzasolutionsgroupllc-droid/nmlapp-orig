Section 1 — Player List & Data Tables
The current app shows every stat column in a massive table — fine on desktop, impossible on phone. Here are the 3 industry approaches, with real NML data so you can see exactly how each would feel.
Option A — Card View
Option B — Column Groups
Option C — List + Tap Detail
Option A — Card View

Each player shows as a card with their key info visible. Tapping a card expands it to show core stats and action buttons. All data is still accessible — just reorganized.

✓ Used by: ESPN app, NFL Fantasy, most modern sports apps
✓ Thumb-friendly, easy to scan, no horizontal scroll
✗ Can't compare multiple players side-by-side easily
✗ Seeing 40+ stats requires tapping each player individually

Option B — Column Groups (Category Toggle)

The table stays a table, but stat columns are grouped into categories (Core, Speed, Receiving, etc.). Tap a category button to swap which columns are showing. Name/OVR/POS always stay pinned on the left.

✓ Used by: Pro Football Reference, 2K Sports, many fantasy tools
✓ Lets users compare multiple players at once
✓ Power users love it — all data available, just organized
✗ Still requires horizontal attention on small phones
✗ Slightly more cognitive load to learn the groups

Section 2 — Mobile Navigation
The current sidebar works great on desktop but on phone it either takes up the full screen or disappears. Here are the two standard approaches used by modern mobile apps.
Option A — Slide-Out Drawer
Option B — Bottom Tab Bar
Option A — Slide-Out Drawer (Hamburger Menu)

A ☰ button in the top bar opens a menu that slides in from the left. All navigation items are accessible. Works for any number of menu items.

✓ Used by: Gmail, Google Drive, Discord (mobile), most feature-rich apps
✓ Supports unlimited nav items — perfect for your 15+ pages
✓ Familiar to most phone users
✗ One extra tap to navigate vs. bottom bar
✗ Menu is hidden by default — less discoverable for new users
Tap ☰ to open menu

✓ Key pages are always one thumb-tap away — fastest navigation
✓ Very discoverable — users see it immediately
✗ Limited to ~5 items in the bar — admin pages go in "More"
✗ Takes up 54px of screen height permanently

My Recommendation
📱 For Tables: Option C (List + Tap Detail) — with Option B available on desktop

Option C gives your league members the fastest mobile experience — quick scanning of players with one tap to see everything. Option A (cards) is close but takes more screen space per player. Option B (column groups) is excellent for power users but can feel complex on a small phone.

Best approach: Use Option C on mobile automatically, and keep the full table view on desktop. This is exactly how the ESPN app, NFL app, and most fantasy tools handle it — same data, different presentation per device.

📍 For Navigation: Option A (Slide-Out Drawer)

Your app has 15+ pages including admin tools. A bottom bar only fits 4–5 items comfortably, meaning most of your pages would live in a "More" menu anyway — defeating the purpose. The drawer handles unlimited items cleanly, and Discord itself uses this exact pattern on mobile, which your users are already familiar with.

Best approach: Slide-out drawer on mobile, existing sidebar on desktop. One hamburger button replaces the sidebar on small screens.
