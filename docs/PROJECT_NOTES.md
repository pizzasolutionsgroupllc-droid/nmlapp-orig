## How to Start the App

Tab 1 — Flask API:
cd /Users/j/Desktop/Claude/nmlapp/backend && /Applications/Xcode.app/Contents/Developer/usr/bin/python3 app.py

Tab 2 — File server:
/Applications/Xcode.app/Contents/Developer/usr/bin/python3 -m http.server 8080 --directory /Users/j/Desktop/Claude/nmlapp --bind 127.0.0.1

Then open: http://127.0.0.1:8080/nml-app.html
