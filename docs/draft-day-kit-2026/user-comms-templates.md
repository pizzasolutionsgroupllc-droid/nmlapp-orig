# User Comms Templates — Copy/Paste to Discord

Pre-written messages for draft-day scenarios. Edit the placeholders in brackets before posting.

---

## Before the draft

**T-30 min warning:**

```
🏈 Draft starts in 30 minutes. Please log in to the app now and refresh your tab — this helps us spot issues early.
```

**T-10 min warning:**

```
🏈 Draft starts at 5:00 PM PT (10 min). Refresh your app tab one more time. On the clock? Have your pick ready.
```

**Draft starting:**

```
🎯 DRAFT IS LIVE. On the clock: [TEAM]. Pick timer: [TIMER] min. Let's go.
```

---

## Minor issues (no action from users needed)

**Brief slowdown, under 30 sec:**

```
⏳ The app is running a little slow right now — give it 15-30 seconds before retrying. Pick timer is unaffected.
```

**503 "busy" errors:**

```
If you see a "draft is busy" message, just wait a moment — the app retries automatically. No need to refresh.
```

---

## User action required

**Everyone please refresh:**

```
🔄 Please refresh your app tab now (Ctrl/Cmd+R). We cleared a minor issue and a refresh will pick up the fix.
```

**Hard refresh if normal refresh doesn't fix it:**

```
If a normal refresh doesn't help, do a hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).
```

---

## Planned restart

**Brief restart notice:**

```
🔧 Quick 2-minute restart to clear a memory issue. No picks will auto-advance during this window. I'll confirm when we're back.
```

**We're back:**

```
✅ Back up. Refresh your tab. Current pick: [TEAM] on the clock, ~[XX] minutes remaining.
```

---

## Pick / advance issues

**Pick didn't advance automatically:**

```
[TEAM]'s pick is being recorded — one moment while I advance manually. No action needed from the next team yet.
```

**Timer expired, manual advance:**

```
Timer expired on [TEAM]. Advancing now — [TEAM]'s pick goes to the makeup queue. On the clock: [NEXT TEAM].
```

---

## Worst case

**Extended pause:**

```
⚠️ Draft is paused while we fix an issue. No pick timers are running. I'll post another update in 5 minutes.
```

**Rolled back to backup:**

```
⚠️ We restored from the backup taken at [TIME PT]. If your last action was after that time, please re-do it. Everything before [TIME PT] is intact.
```

---

## After the draft

**Friday wrap:**

```
🎬 Rounds 1 & 2 complete. See you tomorrow at 11 AM PT for rounds 3-7.
```

**Saturday wrap:**

```
🏆 Draft complete. Results are locked in the app. Good draft, everyone.
```
